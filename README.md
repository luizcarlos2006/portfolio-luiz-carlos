# Portfólio — Luiz Carlos

Site pessoal feito com Next.js 16, React 19 e Tailwind CSS 4. Página única, estática.

## Rodar

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # gera a versão de produção
npm run lint     # checagem de tipos
```

## Onde mexer

Todo o texto está em `src/data/`:

- `perfil.ts`: nome, cargo, resumo, contatos e endereço do site.
- `curriculo.ts`: experiência, cursos, tecnologias, habilidades e projetos.

O CV para download fica em `public/`.
